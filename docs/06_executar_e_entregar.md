# 6. Executar e entregar

## Executar o script no VS Code

1. Abra a pasta do projeto no VS Code.
2. Ative o ambiente virtual, conforme o guia 02.
3. Confirme que `varejo.csv` está na mesma pasta de `analise_varejo.py`.
4. No terminal, execute:

```powershell
python analise_varejo.py
```

5. Leia as informações exibidas no terminal.
6. Abra a pasta `resultados/` para verificar o CSV limpo e os dois gráficos.

## Executar o notebook

Abra `analise_varejo.ipynb` no VS Code com a extensão Jupyter, no Jupyter Notebook ou no Google Colab. Execute as células de cima para baixo. Não pule células, porque as próximas dependem da variável `df` criada nas anteriores.
